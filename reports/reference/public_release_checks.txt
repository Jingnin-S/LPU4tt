Generated build trees, virtual environments, simulator work directories, and
large cycle-vector files were removed before packaging.

RTL/container checks
--------------------
The host has no bare iverilog/verilator on PATH, so the locked
ghcr.io/librelane/librelane:3.0.14 image was used for simulation and lint.
The host Python 3.11 model generated the six vector sets first; the container
then ran scripts/run_device_rtl.py --simulator iverilog --vectors-root ... .
Icarus 13.0 and Verilator 5.044 both completed successfully.  Profiles were
64:1, 64:2, 128:1, 128:2, 256:1, and 256:2; each had 67 cases, and the
aggregate was 791566 cycles.  The per-profile compact record is in
reports/reference/device_public_rtl_regression_summary.json.

The same image, with the separately locked cocotb 2.1.0 site-packages cache,
ran scripts/run_device_cocotb.py for the public 64:1 profile and passed the
pin-only independent arithmetic test.  No STA or physical claim is inferred
from this test.  The image does not include GNU make, so the template Makefile
was not invoked; the dedicated cocotb runner is the executed equivalent.

Release boundary
----------------

submission was performed.
