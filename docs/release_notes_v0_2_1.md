# LPU4tt v0.2.1

Publication date: 2026-11-05. This is the first LPU4tt GitHub publication,
based on the previously curated Tiny-LPU v0.2.0 source tree.

- Consolidated ISA v0.1, functional/resource/full-device models and reproduction.
- Published English specifications, study summaries and an editable architecture figure.
- Clearly separated the qualified 64B/one-lane macro from expansion candidates.
- Included fresh compact ISA/device/ESL results and a reproducible software CI entry.
- Preserved MIT licensing and upstream notices.

There are no changes to ISA encoding, numeric behavior, model scheduling or
qualified RTL. The Python package retains its existing tinylpu import name.
Historical ideal-port and resource studies remain explicitly labeled.
GDS/PDK/work caches are not Git contents.
